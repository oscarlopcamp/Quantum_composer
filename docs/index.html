Cómo usar la versión completa

Esta página es solo una demo. La aplicación completa usa PyQt5 y Qiskit, simula con Qiskit Aer, dibuja la qsphere y exporta imágenes del circuito. Necesitas Python 3.12.

  1. Clona el repositorio: 
    git clone https://github.com/oscarlopcamp/Quantum_composer.git
cd Quantum_composer
  2. Crea y activa un entorno virtual: 
    # Windows (PowerShell)
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1

# macOS / Linux
python3.12 -m venv .venv
source .venv/bin/activate
  3. Instala las dependencias: 
    python -m pip install --upgrade pip setuptools wheel
pip install -r requirements.txt
  4. Ejecuta la aplicación: 
    python main.py
